# 和紙 (Washi) — Slack Sidebar Themes

Paste into **Preferences → Themes → Custom Theme** in Slack.

## Light

```
#e6e5e2,#c0bdb8,#1a4a70,#f0f0ee,#c0bdb8,#1a1816,#2a5828,#8a2820
```

## Dark

```
#1e1c1a,#3a3632,#7a8fa0,#e8e4df,#3a3632,#c8c3ba,#8a9e78,#c07068
```

## Field order

`Column BG, Menu BG Hover, Active Item, Active Item Text, Hover Item, Text Color, Active Presence, Mention Badge`
